# 安装与连接

## 准备

- Android TV / Google TV 8.0（API 26）或更新版本，带方向、确认和返回键的遥控器。
- 已运行的 Navidrome，以及可登录的账号。
- 可以互相访问的手机和电视；电视能够访问 Navidrome 地址。

当前以 Navidrome 为目标实现 Subsonic API。尚未验证其他兼容服务器的全部行为。

## 构建与安装

公开仓库当前提供源码。安装 JDK 17、Android SDK Platform 34 和相应构建工具后，在仓库根目录运行：

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

有多个 ADB 设备时，使用 `adb -s <设备序列号> ...` 指定电视。也可以通过自己的 APK 侧载工具安装。

SDK 可使用 `ANDROID_HOME`，或在未提交的 `local.properties` 中设置 `sdk.dir`。源码不包含私人服务器地址、账号或签名密钥。[开发说明](development.md)

## 手机扫码配置

1. 在电视打开应用，用手机扫描屏幕上的二维码。
2. 在手机浏览器填写 Navidrome 地址、用户名与密码。
3. 提交后由电视验证服务器连接；验证成功进入歌曲页。

请填写电视能够访问的完整服务器地址，例如 `http://music-server.local:4533`，包括实际使用的子路径。二维码页面由电视临时提供，手机也需要能访问电视。

配置保存在电视本机，密码通过 Android Keystore 加密。连接设置中可重新扫码配置，或退出登录；重新配置只有验证成功后才替换原设置。

## 日常使用

首页浏览所有歌曲；也可通过侧栏进入歌手、专辑、歌单与收藏。确认选中的歌曲即可播放，当前歌曲再次确认可暂停／继续；向右打开歌曲操作面板。

从侧栏「正在播放」或底部迷你播放器进入播放页，初始焦点在播放／暂停按钮。上一首、下一首和播放模式均可用方向键操作。在进度条上按左右，每次调整 10 秒。

播放模式入口提供顺序、随机、单曲循环和列表循环。队列中可跳转或移除歌曲。返回键关闭面板或回到上一页；回到列表时恢复浏览位置。

## 连接不通时

先确认手机能访问电视、电视能访问服务器。访客 Wi-Fi、客户端隔离、VPN 和防火墙可能阻止设备互访。

Android 模拟器通常使用 NAT，二维码里的模拟器内部地址无法直接由手机访问；这与真实电视在局域网内的情况不同。模拟器开发可使用主机端口转发／中继，扫码配对建议直接在电视上验证。应用没有要求使用遥控器输入地址或账号的备用表单。

## 音质和缓存

设置中可切换原音与相容模式。相容模式请求 MP3、最高 192 kbps；服务器需具备相应转码能力，切换后新准备的播放项采用新设置。

封面使用本地内存与磁盘缓存。服务器替换了同一 ID 的封面时，可以在设置中清除封面缓存后重新进入页面。
